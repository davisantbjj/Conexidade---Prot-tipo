# VozBairro — protótipo

Protótipo interativo em HTML do VozBairro (ocorrências do bairro, mapa real de Aracaju, botão SOS).

## Abrir

- **Online:** GitHub Pages deste repositório.
- **Local:** dê dois cliques em `Abrir VozBairro.bat` (precisa de Python) ou abra `index.html` direto no navegador.

## Editar

As telas ficam em `screens/*.dc.html`. Depois de editar, rode `python build.py` para regenerar `screens.js`.
